SLEEP NOTES FOR CROSSPOINT

Your notes are plain text files in the Notes folder.
Open them from the Library like any book.

SEND A NOTE FROM YOUR IPHONE
1. On the reader, open File Transfer and join your home WiFi.
2. On the iPhone (same WiFi), open a note in Notes.
3. Tap Share, then choose the "Send to X3" shortcut.
4. The note appears in the Notes folder.

NOTE AS SLEEP SCREEN
1. Settings > Display > Sleep Screen > Custom.
2. With File Transfer on, open http://crosspoint.local/files
   on a phone or computer. Press Save to reader: the
   note is saved and drawn into sleep/note.bmp.
3. Any other .bmp files in the sleep folder are deleted
   first, so the note is the only sleep image. Cached
   sleep images in .crosspoint (names containing
   "sleep") are deleted too.

WRITE A NOTE FROM A BROWSER
The same Notes card lets you write, save, delete notes,
and turn any note into the wallpaper.

If crosspoint.local does not load, use the IP address
shown on the reader's File Transfer screen.
